# Agent Config Registry

A spec-first open-source project for assembling versioned Agent, Skill, and Prompt configuration into reproducible experiment releases. Import existing JSON, bind assets in a visual editor, and read the full release through one experiment tag.

当前在评审 v0.1 设计。项目允许导入已有 JSON、为组内每个 Agent 绑定具体的 Skill 和 Prompt 版本，并按一个实验 tag 读取整组已发布配置。
